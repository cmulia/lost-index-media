## Instagram caption
The first text message got no reply. 📱

On 3 December 1992, test engineer Neil Papworth sent "Merry Christmas" from a computer to Richard Jarvis's Orbitel 901 handset on Vodafone's network.

Handsets could not send texts yet, so there was no way to text back. Papworth says people phoned him from the party instead.

In December 2021 an NFT of a replica of the message sold at auction in Paris for about 100,000 euros, with the proceeds going to the UN refugee agency.
